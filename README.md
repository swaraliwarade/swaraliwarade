## 🌙 a small introduction

i'm **swarali** — a computer engineering student who likes turning vague ideas into things that actually run.

most of my projects start the same way: *"wouldn't it be funny if…"* → a rough sketch → a prototype → something people can click. i like the messy middle best. i'm happiest around **ai, full-stack web, and data** — and around hackathons, where a weekend is somehow exactly enough time.

i learn by poking at things until they make sense, and i'm unreasonably attached to small details nobody asked for.

> curiosity → experiment → build → break → debug → repeat ✩
